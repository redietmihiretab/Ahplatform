# Amde Haymanot Sunday School (ዓምደ ሃይማኖት ሰንበት ትምህርት ቤት)

Official links and social channels web portal for **Amde Haymanot Sunday School**, Ethiopian Orthodox Tewahedo Church.

> « ንቁ በሃይማኖት ቁሙ » — ፩ኛ ቆሮንቶስ ፲፮:፲፫ (1 Corinthians 16:13)

---

## 🌟 Features
- **UI/UX Pro Max Design**: Mobile-first, responsive, accessible layout with tactile feedback.
- **Sacred Aesthetic**: Warm parchment (`#f6f0e4`) and radiant gold theme inspired by traditional Ethiopian church manuscripts and iconography.
- **Official Social Channels**:
  - **YouTube**: Sermons, spiritual songs & video teachings
  - **Telegram**: Announcements, readings & official community channel
  - **TikTok**: Short clips, mezmur & reminders
  - **Instagram**: Sunday school events & photo galleries
  - **Facebook**: Official church community page

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or serve locally:

```bash
# Using Python
python -m http.server 3000

# Using Node.js
npx serve
```

Visit `http://localhost:3000`.
